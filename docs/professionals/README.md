# Материалы отбора на чемпионат «Профессионалы»

Объявление-постер и текст рассылки для отбора студентов колледжа на Всероссийский
чемпионат профессионального мастерства «Профессионалы» (3 компетенции:
Программные решения для бизнеса, Веб-технологии, Разработка мобильных приложений).

## Состав

| Файл / папка | Назначение |
|---|---|
| `poster.png` | Готовый постер 1080×1350 для публикации и рассылки в Max |
| `message.md` | Текст объявления для рассылки в Max (каналы) |
| `poster.html` | Исходник постера (HTML/CSS, верстка 540×675 @2x) |
| `qr/` | QR-коды тестовых заданий (PNG 1024px, ECC M) |
| `tasks/` | Конкурсные задания по компетенциям (PDF/DOCX), на них ведут QR |
| `assets/` | Логотип движения, эмблема колледжа, паттерн, шевроны, шрифт Roboto |
| `tools/generate-qr.js` | Скрипт перегенерации QR-кодов |

## Как перегенерировать постер

1. Поднять локальный сервер в этой папке (шрифты не грузятся с `file://`), например:
   `npx serve .` или мини-сервер на Node.
2. Отрендерить в Chrome headless:
   ```
   chrome --headless=new --force-device-scale-factor=2 --window-size=540,675 \
          --hide-scrollbars --user-data-dir=<профиль> \
          --screenshot=poster.png "http://127.0.0.1:ПОРТ/poster.html"
   ```
3. Проверить PNG: 1080×1350.

## QR-коды

QR ведут на файлы конкурсных заданий в этой папке сайта (ветка `master`):

- `tasks/programmnye-resheniya-04.docx` (Программные решения для бизнеса)
- `tasks/veb-tehnologii-04.docx` (Веб-технологии)
- `tasks/mobilnye-prilozheniya-04.docx` (Разработка мобильных приложений)

Чтобы перегенерировать QR после смены путей — отредактировать URL в
`tools/generate-qr.js` и запустить скрипт (требуется Node.js 18+).
