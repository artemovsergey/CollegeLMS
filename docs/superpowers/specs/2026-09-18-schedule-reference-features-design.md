# Дизайн-спецификация: справочники расписания и интеграция слоёв (звонки, нерабочие дни, вставки, практики)

**Дата:** 2026-09-18
**Статус:** утверждено пользователем (план в чате)
**Цель:** реализовать оставшиеся требования домена расписания: управление звонками, нерабочие дни, специальные вставки, практики УП/ПП (+ импорт XLSX), семестровый экспорт, веб-раздел «Изменения», журнал преподавателя с бейджами.

## 1. Границы

Входит: backend-справочники и их интеграция в расписание/корректировки/экспорт/бот, страницы диспетчера (`/dispatcher/bells`, `/dispatcher/holidays`, `/dispatcher/inserts`, `/dispatcher/practices`), веб `/changes`, `/teacher/journal`, семестровый экспорт.

Не входит (отдельная итерация): миграция бота и мини-приложения на batch-модель корректировок (UC-SCH-40/43).

## 2. Модель данных

| Сущность | Поля | Правила |
|----------|------|---------|
| `BellSlot` | `NumberPair` (1–8), `StartTime`, `EndTime` | уникальный номер пары; 07:00–21:00; возрастание; без пересечений |
| `BigBreak` | `AfterPair` (1–8), `StartTime`, `EndTime` | не более одной; 07:00–21:00; `StartTime < EndTime` |
| `NonWorkingDay` | `DateFrom`, `DateTo`, `Title` | `DateFrom ≤ DateTo`; одиночная дата — совпадают |
| `Practice` | `Kind` (`Up`/`Pp`), `GroupId`, `TeacherId`, `DateFrom`, `DateTo`, `Organization?`, `Note?` | период в семестре; пересечение практик одной группы → 409 |
| `ScheduleInsert` | `Title`, `DayOfWeek`, `StartTime`, `EndTime`, `Course?` (1–4), `IsActive` | `StartTime < EndTime`; не занимает номер пары |

Сиды:
- звонки: 8 пар 08:30–20:55 с большой переменой 45 минут после 4-й пары (в пределах 07:00–21:00);
- вставки: «Разговор о важном» (Пн 08:30–09:00), «Классный час» (Чт 12:10–13:00), все курсы, активны.

## 3. API-контракты

### 3.1 Звонки
```
GET /api/bells → Result<BellScheduleResponse>
PUT /api/bells → Result<BellScheduleResponse>   (Dispatcher/Admin)
```
`BellScheduleResponse { slots: [{id, numberPair, startTime, endTime}], bigBreak: {afterPair, startTime, endTime} | null }`.
`PUT` заменяет справочник целиком. Валидации → `400` на русском (диапазон, порядок, пересечения, большая перемена).

### 3.2 Нерабочие дни
```
GET    /api/non-working-days?from=&to=&page=&pageSize=   (все роли)
POST   /api/non-working-days                             (Dispatcher/Admin)
PUT    /api/non-working-days/{id}
DELETE /api/non-working-days/{id}
```

### 3.3 Вставки
```
GET    /api/schedule/inserts?dayOfWeek=&course=&activeOnly=  (все)
POST   /api/schedule/inserts, PUT/DELETE /{id}               (Dispatcher/Admin)
```

### 3.4 Практики
```
GET    /api/practices?groupId=&teacherId=&kind=&from=&to=&page=&pageSize=  (все)
POST   /api/practices, PUT/DELETE /{id}                                    (Dispatcher/Admin)
POST   /api/practices/import/preview   (multipart file)
POST   /api/practices/import/confirm   { rows }
```
Импорт: шапка в строке 1 (`Вид | Группа | Дата начала | Дата окончания | Преподаватель | Организация | Примечание`), данные со строки 2; ошибки «Строка N: …»; подтверждение только без ошибок; транзакция.

### 3.5 Экспорт
```
GET /api/schedule/export?scope=day|week|semester&format=pdf|xlsx&layout=grid|daycards&groupId=&teacherId=&room=&period=&date=&week=
```
Семестровый вид: матрица «недели × дни Пн–Сб»; в ячейке пары (номер, предмет, преподаватель, аудитория, бейджи), вставки, практики; нерабочие дни помечены. Имя файла — FILE-3.

## 4. Интеграция слоёв

- **Звонки** — единый источник времени: чтение расписания (`GET /api/schedule`, календарь, бот, мини-приложение через API) отображает время из справочника по номеру пары; корректировки создают пары с временем из справочника; экспорт использует справочник.
- **Нерабочие дни** — создание/применение корректировки на нерабочую дату → `400`; расписание дня на нерабочую дату не выводится; бот не отправляет рассылку и показывает сообщение; экспорт помечает даты.
- **Вставки** — отдельная строка дня (без номера пары), видны в вебе, мини-приложении, боте и экспорте; неактивные скрыты.
- **Практики** — в период практики группы её обычные пары заменяются карточкой УП/ПП; в расписании преподавателя отображается блок практики; видны во всех интерфейсах и экспорте.
- **Журнал** — бейджи корректировок (`Add/Replace/Move`, «сам.р.»), снятые даты скрыты, фильтр по предмету.
