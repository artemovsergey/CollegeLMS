# Дизайн: UI-фиксы и улучшения (июль 2026)

## 1. Карта контактов

- **Проблема**: координаты `45.0450,41.9808` ставят метку не на то здание
- **Решение**: заменить `q=45.0450,41.9808&output=embed` на `q=ГБПОУ+Ставропольский+колледж+связи+имени+Петрова&output=embed` — Google Maps сам найдёт адрес и поставит метку на здание
- **Файл**: `CollegeLMS.Next/app/(public)/contacts/page.tsx` строка 42

## 2. Перенос иконок темы/адаптивности в первый хедер

- **Проблема**: ThemeToggle и AccessibilityToggle во втором ряду хедера, нужно в первом
- **Решение**:
  - Перенести `<AccessibilityToggle />` и `<ThemeToggle />` из Row 2 (сейчас строка 123-125) в Row 1, в правую часть
  - Удалить кнопку «Войти» из Row 1 (строка 99-101)
  - В Row 2 убрать обёртку `[&_button]:!text-white/80` (так как там больше нет этих кнопок)
- **Файл**: `CollegeLMS.Next/components/Header.tsx`

## 3. Фикс видимости иконок в тёмной теме / адаптивности

- **Проблема**: в `.dark` фоне хедера (#568edd) иконки `text-white/80` малозаметны; в `.accessibility-mode` иконки сливаются с принудительно белым фоном
- **Решение**:
  - В Row 1: иконки `text-white/90 hover:text-white` на кнопках с `hover:bg-white/10`
  - В `.accessibility-mode`: кнопки темы/адаптивности получают `!text-black !bg-black/10`
- **Файл**: `CollegeLMS.Next/components/Header.tsx` + `CollegeLMS.Next/app/globals.css`

## 4. Раздел «Сотруднику»

- **Проблема**: кнопка входа и профиль в хедере не нужны на публичном сайте
- **Решение**:
  - Удалить блок `{!user && <Link to="/login">...}` из Row 1
  - Удалить блок `{user && (профиль-попап)}` из Row 2
  - В `data/site-content.ts` добавить раздел `Сотруднику` с ссылкой `/employee`
  - На `/employee` странице будет форма входа и контент для сотрудников
- **Файлы**: `Header.tsx`, `data/site-content.ts`, новый `app/(public)/employee/page.tsx`

## 5. Размер шрифта

- **Проблема**: базовый шрифт 16px (браузерный дефолт)
- **Решение**: `body { font-size: 17px }` — все rem-величины масштабируются автоматически
- **Файл**: `CollegeLMS.Next/app/globals.css`

## 6. Футер — цвет фона

- **Проблема**: `bg-white` сливается с основной частью страницы
- **Решение**: сменить на `bg-muted` (`#eef0f4`)
- **Файл**: `CollegeLMS.Next/components/Footer.tsx` строка 61

## 7. Приёмная кампания в хедере

- **Проблема**: нет акцента на приёмной кампании в верхней части сайта
- **Решение**: добавить ссылку «🔥 Приёмная кампания 2026» в Row 1 после ссылок (с амбер-акцентом `text-amber-300 font-semibold`)
- **Файл**: `CollegeLMS.Next/components/Header.tsx`

## 8. Логотипы партнёров

- **Проблема**: вместо реальных логотипов компаний используются абстрактные Lucide-иконки
- **Решение**: заменить на стилизованные inline SVG-логотипы:
  - ОДК-Сатурн — турбина с фирменным синим
  - Военный университет радиоэлектроники — звезда + радиоволны
  - Министерство энергетики СК — стилизованная молния/шестерня
  - Ростелеком — буквы RT в фирменном зелёном
  - ЭР-Телеком — буквы ЭР в фирменном бирюзовом
- **Файл**: `CollegeLMS.Next/components/PartnersSection.tsx`

## 9. Превью видео в СМИ

- **Проблема**: нет превью видео, только ссылка с иконкой
- **Решение**: 
  - Получить thumbnail через Rutube API: `https://rutube.ru/api/video/1b0e5af3e47d34c76be2a3dd66c77fd5/thumbnail/`
  - Показать превью-картинку + кнопку Play
  - По клику — открывать iframe Rutube плеера в модальном окне
- **Файл**: `CollegeLMS.Next/components/MediaSection.tsx`
