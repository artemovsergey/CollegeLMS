# MaxBot: меню-навигация по расписанию (день/неделя/дата)

Дата: 2026-09-07
Статус: утверждена пользователем

## Контекст

MaxBot — бот расписания в мессенджере MAX. Сейчас навигация построена на
слэш-командах (`/schedule`, `/week`), дневной вид показывает только
дни недели со стрелками «пред/след», недельный вид лишён навигации, а
выбрать конкретную произвольную дату нельзя. Пользователь хочет: после выбора
роли (Студент/Преподаватель) и сущности (группа/преподаватель) удобное
меню-расписание без слэш-команд с перемещением по дням, неделям и конкретным
датам.

Пункты о собственной организации/API в MAX и о мини-приложении с расписанием —
отложены отдельными задачами (исследуются пользователем).

## Цели

- Убрать слэш-команды из пользовательского интерфейса (кроме `/start` для
  совместимости) — вся навигация кнопками.
- Расписание по группе (Студент) и по преподавателю (Преподаватель) — по неделе,
  по дню, по конкретной дате.
- Перемещение: пред/след день, пред/след неделя, календарь месяцев.
- Весь флоу без состояния в памяти — каждый callback самодостаточен.

## Подход

**Дата-центричная навигация.** Бот внутренне оперирует реальными датами
(якорь), передаваемыми в payload кнопок. Номер недели и день недели для API
вычисляются из даты: `week = StudyWeek.ForDate(date)`,
`dayOfWeek = (int)date.DayOfWeek`. Основное API (`GET /api/schedule`) поддерживает
фильтры `week` и `dayOfWeek` одновременно (фильтры складываются) — отдельные
изменения бэкенда не нужны.

Прочие payload-ы (`group:id`, `teacher:id`, `page:…`, `role`, `settings`,
`notify*`) сохраняют текущий формат.

## Модель payload

| Payload | Назначение |
|---------|------------|
| `menu` | Главное меню |
| `today` | Показать расписание на сегодня |
| `day:yyyy-MM-dd` | Показать конкретный день |
| `week:yyyy-MM-dd` | Показать неделю, содержащую дату (якорь — любой день недели) |
| `dayprev:yyyy-MM-dd` / `daynext:yyyy-MM-dd` | Предыдущий/следующий день от якоря |
| `weekprev:yyyy-MM-dd` / `weeknext:yyyy-MM-dd` | Предыдущая/следующая неделя от якоря |
| `cal:yyyy-MM` | Открыть календарь месяца |
| `calprev:yyyy-MM` / `calnext:yyyy-MM` | Листать месяц календаря |

Дата в payload — `DateTime` в формате `yyyy-MM-dd` (локальное время МСК);
якорь дня — сам день, якорь недели — понедельник недели.

## Экраны

Все экраны — inline-клавиатура через `SendInlineKeyboardAsync`.

### Онбординг
`bot_started` / `/start` → выбор роли (`role:student` / `role:teacher`) →
список групп/преподавателей с пагинацией (`page:groups:N` / `page:teachers:N`) →
выбор (`group:id` / `teacher:id`). После выбора — **Главное меню**
(вместо текущего текста со слэш-командами).

### Главное меню (`menu`)
Заголовок: имя роли и выбранная сущность.
Кнопки:
- 📅 Сегодня → `today`
- 📆 Неделя → `week:текущая_дата`
- 🗓 Дата → `cal:текущий_месяц`
- ⚙️ Настройки → `settings`

Доступен из любой точки через кнопку «🔙 Меню».

### Экран дня (`day`, `dayprev`, `daynext`, выбор через календарь/неделю)
Заголовок: «Понедельник, 07.09 — Группа/Преподаватель».
Тело: `FormatDaySchedule` (с датой в заголовке).
Кнопки:
- `dayprev:дата` / `daynext:дата` по краям ряда
- 📆 Неделя → `week:дата`
- 🔙 Меню → `menu`

Воскресенье: показывается сообщение «выходной», навигация работает.

### Экран недели (`week`, `weekprev`, `weeknext`)
Заголовок: «Расписание на неделю 07.09–13.09 — Группа/Преподаватель».
Тело: `FormatWeekSchedule` (с диапазоном дат в шапке).
Кнопки:
- Пн 07.09 … Вс 13.09 (7 кнопок) → `day:дата`
- `weekprev:дата` / `weeknext:дата`
- 🗓 Дата → `cal:месяц_якоря`, 📅 Сегодня → `today`, 🔙 Меню → `menu`

Если текст недели > 4000 символов — сообщение-шапка с навигацией и кнопками
(отдельное), затем текстовые сообщения по дням без кнопок.

### Календарь (`cal`, `calprev`, `calnext`)
Заголовок: «Сентябрь 2026».
Тело: сетка кнопок по 7 колонок (Пн–Вс), каждая дата → `day:дата`.
Кнопки:
- `calprev:месяц` / `calnext:месяц`
- 📅 Сегодня → `today`, 🔙 Меню → `menu`

### Настройки
Текущий экран `ShowSettingsAsync` сохраняется; добавляется кнопка
«🔙 Меню» → `menu`. Смена роли/группы/преподавателя после выбора ведёт в
Главное меню.

## Компоненты и файлы

- `Bot/MaxBotService.cs` — рефакторинг:
  - `SendScheduleAsync` / `SendWeekScheduleAsync` заменяются на
    `ShowDayAsync(DateTime date)`, `ShowWeekAsync(DateTime date)`,
    `ShowCalendarAsync(DateTime month)` (все берут настройки пользователя и
    строят киборды), `ShowMainMenuAsync`.
  - Обработка текстовых команд: `/start`, `/help`, `/settings` остаются
    (совместимость), текст /help упрощается. `/schedule`, `/week` — удаляются.
  - Парсер callback-payload выносится в тестируемый статический
    `CallbackPayload.Parse`.
  - Удаляется мёртвый код `InteractionState` и `_states` (нигде не
    устанавливаются).
  - Helpers «дата ↔ неделя» — в `StudyWeek` (уже есть `MondayOf`, `ForDate`,
    `Current`) + `ToApiDay` из `MessageFormatter`.
- `Services/MessageFormatter.cs` — форматирование дат: `FormatDaySchedule`
  принимает дату, `FormatWeekSchedule` принимает `weekStart` для шапки;
  добавлены месяцы, `dd.MM`, длинный формат даты.
- `Services/CalendarFormatter.cs` (новый) — генерация сетки календаря месяца.
- `Services/CallbackPayload.cs` (новый) — разбор и генерация payload.
- Тесты в `CollegeLMS.MaxBot.Tests`:
  - разбор callback-payload (день/неделя/календарь/стрелки),
  - дата → `week`+`dayOfWeek`,
  - сетка календаря (количество кнопок, перенос месяцев, числа),
  - заголовки дня/недели с датами.

Не изменяются: `MaxApiClient`, `ScheduleNotifier`, `MaxApiClient` endpoints,
основной backend (`CollegeLMS.API`), фронтенд, deploy.

## Обработка ошибок

- Текст не распознан (не слэш): ответ «Используй кнопки меню» + Главное меню.
- Callback с неизвестным payload: логируем, отвечаем Главным меню.
- Пустые группы/преподаватели — как сейчас (не найдены).
- Сетка календаря: пустые ячейки до 1-го числа месяца не рендерятся;
  стрелка `calnext` ограничена текущим семестром/разумной границей
  (не ранее старта семестра, не позже +16 недель).
- Неделя > 4000 символов — шапка с кнопками + текст по дням.
