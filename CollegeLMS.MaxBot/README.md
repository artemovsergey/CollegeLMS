# Бот расписания ГБПОУ СКС — Мессенджер MAX

## Что умеет бот

- Просмотр расписания занятий на день или неделю
- Выбор группы (для студентов) или преподавателя
- Ежедневные уведомления с расписанием (настраиваемые дни)

---

## Быстрый старт

### 1. Найди бота

Открой мессенджер **MAX** и найди бота по имени или нику (указывается при создании бота на платформе).

### 2. Нажми «Начать»

Нажми кнопку **«Начать»** или отправь команду `/start`.

### 3. Выбери роль

Бот предложит выбрать роль:

| Роль | Для кого |
|------|----------|
| **Студент** | Смотрит расписание своей группы |
| **Преподаватель** | Смотрит расписание своих занятий |

Нажми на кнопку с нужной ролью.

### 4. Выбери группу / преподавателя

- **Студент:** бот покажет список групп. Выбери свою группу кнопкой. Если групп много — листай страницы кнопками `← Назад` / `Далее →`.
- **Преподаватель:** аналогично — выбери своё ФИО из списка.

Готово! Бот запомнил твой выбор.

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Регистрация и настройка роли |
| `/schedule` | Расписание на **сегодня** |
| `/schedule пн` | Расписание на **понедельник** |
| `/schedule вт` | Расписание на **вторник** |
| `/schedule ср` | Расписание на **среду** |
| `/schedule чт` | Расписание на **четверг** |
| `/schedule пт` | Расписание на **пятницу** |
| `/schedule сб` | Расписание на **субботу** |
| `/week` | Расписание на **всю неделю** |
| `/settings` | Настройки (смена группы, уведомления) |
| `/help` | Справка по командам |

## Просмотр расписания

### На сегодня
```
/schedule
```
Бот покажет все пары на текущий день недели.

### На конкретный день
```
/schedule пн
```
Доступные сокращения: `пн`, `вт`, `ср`, `чт`, `пт`, `сб`

### На неделю
```
/week
```
Бот покажет расписание с понедельника по субботу (текущая учебная неделя).

### Навигация по дням
После получения расписания бот покажет кнопки:
- `← Пред. день` — предыдущий день
- `След. день →` — следующий день
- `📅 На неделю` — расписание на всю неделю

## Настройки

Отправь `/settings`, чтобы:

### Сменить группу или преподавателя
Нажми **«Сменить группу»** или **«Сменить преподавателя»** и выбери нового из списка.

### Настроить уведомления
1. Нажми **«🔔 Уведомления»**
2. Бот покажет дни недели с галочками
3. Нажми на день, чтобы включить/выключить уведомление в этот день
4. Нажми **«💾 Сохранить»**

**По умолчанию** уведомления включены на **понедельник и пятницу**.

## Уведомления

Каждое утро в **7:30** бот присылает расписание на сегодня — если этот день включён в настройках уведомлений.

Пример сообщения:
```
📋 Понедельник — Группа

1. 📖 Математика
    🕐 09:10–10:40  📍 301
    👨‍🏫 Иванов И.И.

2. ✏️ Физика
    🕐 10:50–12:20  📍 205
    👨‍🏫 Петров П.П.

3. 🔬 Информатика
    🕐 12:30–14:00  📍 110А
```

Если пар нет — бот напишет: «Расписания нет — выходной!»

## Частые вопросы

**Бот не находит мою группу?**
Убедись, что расписание загружено в систему (через админку или импорт XLSX).

**Уведомления не приходят?**
Проверь настройки: `/settings` → 🔔 Уведомления. Убедись, что нужный день включён и стоит галочка.

**Хочу сменить группу mid-semester?**
Отправь `/settings` → «Сменить группу» и выбери новую. Старые данные сохраняются, пока не выберешь новую.

**Бот отправляет расписание не на тот день?**
Проверь, что в настройках указана правильная роль (студент/преподаватель) и группа/преподаватель.

## Разработка и развёртывание

### Запуск (Docker)

Бот поднимается в общем compose под профилем `max-bot`:

```powershell
docker compose --profile max-bot up --build -d
```

Конфигурация через env:

| Переменная | Назначение |
|-----------|------------|
| `MAX_BOT_TOKEN` | Токен бота (выдаётся на platform-api2.max.ru при создании бота) |
| `MAX_BOT_DB_NAME` | Имя БД (по умолчанию `collegelms_maxbot`) |
| `DB_USER` / `DB_PASSWORD` | Учётка PostgreSQL |

### БД

Настройки пользователей хранятся в **отдельной** базе `collegelms_maxbot`
(таблица `user_settings`). Схема создаётся автоматически при первом старте
(`EnsureCreated`), основная БД `collegelms` не затрагивается.

### Часовой пояс

По умолчанию `Europe/Moscow` (IANA). На Windows при необходимости можно
переключить на `Russian Standard Time` в `appsettings.json`
(`MaxBot:TimeZone`). Уведомления отправляются в `07:30` по МСК.

### Учебная неделя

Номер текущей недели вычисляется от начала семестра `2026-09-01`
(см. `Services/StudyWeek.cs`) и передаётся в API как фильтр `week`.

### Заметка про SSL

Клиент MAX игнорирует валидацию TLS-сертификата
(`DangerousAcceptAnyServerCertificateValidator`) — требуется для работы с
российским CA платформы в Docker. В продакшене допустимо только в связке с
локальным токеном и ограниченным доступом к контейнеру.
