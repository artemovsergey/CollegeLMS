# Практическая работа 20. Обработка ошибок от сервера

### **Тема занятия**

---

### **Цель работы**

Научиться обрабатывать ошибки API единообразно: статусы, сообщения, ретраи.

---

### **Задание**

Доработайте приложение из практической работы 19:

1.  Единый обработчик ошибок: axios interceptor, который извлекает сообщение из тела ответа (`data.message`) и прокидывает как Error.
2.  Компонент `ErrorBanner` — переиспользуемый блок ошибки с кнопкой «Повторить».
3.  Классификация ошибок:
    *   400 — показ сообщения валидации из ответа сервера;
    *   401 — редирект на `/login` с очисткой токена;
    *   500 — «Внутренняя ошибка сервера»;
    *   сетевые — «Нет соединения с сервером».
4.  Автоматический повтор (retry) для таймаутов: до 3 попыток с задержкой 1с (через TanStack Query или вручную).

---

### **Пример кода**

```tsx
api.interceptors.response.use(
  res => res,
  error => {
    const status = error.response?.status;
    let message = "Нет соединения с сервером";

    if (error.response?.data?.message) {
      message = error.response.data.message;
    } else if (status === 401) {
      localStorage.removeItem("token");
      window.location.href = "/login";
      message = "Сессия истекла";
    } else if (status === 500) {
      message = "Внутренняя ошибка сервера";
    }

    return Promise.reject(new Error(message));
  }
);
```
