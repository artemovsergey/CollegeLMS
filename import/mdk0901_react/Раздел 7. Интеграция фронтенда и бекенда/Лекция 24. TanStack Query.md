### **1. Проблемы ручной загрузки данных**

- Каждый монтируемый компонент повторяет запрос.
- Нет кэша — при каждом переходе данные грузятся заново.
- Нет автоматической обработки `loading`/`error`.
- После изменения данных (мутации) нужно вручную перезапрашивать.

### **2. TanStack Query (React Query)**

Установка:

```bash
npm install @tanstack/react-query
```

Обёртка приложения:

```tsx
import { QueryClient, QueryClientProvider } from "@tanstack/react-query";

const queryClient = new QueryClient();

function App() {
  return (
    <QueryClientProvider client={queryClient}>
      <CoursesPage />
    </QueryClientProvider>
  );
}
```

**Чтение данных (`useQuery`):**

```tsx
import { useQuery } from "@tanstack/react-query";

function CoursesPage() {
  const { data, isLoading, error } = useQuery({
    queryKey: ["courses"],
    queryFn: () => api.get<Course[]>("/courses").then(r => r.data),
  });

  if (isLoading) return <p>Загрузка...</p>;
  if (error) return <p className="error">Ошибка</p>;

  return <ul>{data?.map(c => <li key={c.id}>{c.title}</li>)}</ul>;
}
```

**Изменение данных (`useMutation` + инвалидация):**

```tsx
const queryClient = useQueryClient();

const createCourse = useMutation({
  mutationFn: (title: string) =>
    api.post("/courses", { title }).then(r => r.data),
  onSuccess: () => {
    queryClient.invalidateQueries({ queryKey: ["courses"] });
  },
});

createCourse.mutate("Новый курс");
```

После `invalidateQueries` данные перезагружаются автоматически — ручная синхронизация не нужна.

### **3. Сравнение подходов**

| Критерий | fetch/axios вручную | TanStack Query |
|----------|--------------------|----------------|
| Кэш и повторное использование | нет | есть |
| Состояния loading/error | вручную | автоматически |
| Синхронизация после мутаций | вручную | инвалидация |
| Объём кода | меньше | чуть больше |
| Когда применять | простые единичные запросы | приложения с данными и мутациями |
