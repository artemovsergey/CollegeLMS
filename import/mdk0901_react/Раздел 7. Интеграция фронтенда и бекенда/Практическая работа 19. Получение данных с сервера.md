# Практическая работа 19. Получение данных с сервера

### **Тема занятия**

---

### **Цель работы**

Реализовать загрузку данных с сервера с обработкой состояний loading/error/success.

---

### **Задание**

Приложение «Каталог постов» (используйте `https://jsonplaceholder.typicode.com`):

1.  Страница `/posts` — список постов (title + preview). Используйте axios + `useEffect` с паттерном трёх состояний.
2.  Клик по посту — переход на `/posts/:id`, загрузка деталей (body, автор через `/users/:id`).
3.  При ошибке сети показывайте блок ошибки с кнопкой «Повторить» (перезапуск запроса через повторный вызов функции загрузки).
4.  При загрузке — спиннер; при пустом списке — «Постов нет».

---

### **Пример кода**

```tsx
function PostsPage() {
  const [posts, setPosts] = useState<Post[]>([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  const load = useCallback(() => {
    setLoading(true);
    setError(null);
    api
      .get<Post[]>("/posts")
      .then(r => setPosts(r.data))
      .catch(e => setError(e.message))
      .finally(() => setLoading(false));
  }, []);

  useEffect(load, [load]);

  if (loading) return <Spinner />;
  if (error) {
    return (
      <div className="error">
        <p>Ошибка: {error}</p>
        <button onClick={load}>Повторить</button>
      </div>
    );
  }
  if (posts.length === 0) return <p>Постов нет</p>;

  return (
    <ul>
      {posts.map(p => (
        <li key={p.id}>
          <Link to={`/posts/${p.id}`}>{p.title}</Link>
        </li>
      ))}
    </ul>
  );
}
```
