### **1. Что такое React?**

**React** — библиотека JavaScript (TypeScript) для построения пользовательских интерфейсов. В отличие от классического подхода (прямые манипуляции с DOM), React описывает **каким должен быть интерфейс**, а не **как его менять**.

**Основные идеи:**

- **Компоненты** — переиспользуемые куски UI.
- **Декларативность** — вы описываете состояние, React заботится об обновлениях.
- **Виртуальный DOM** — React сравнивает новое дерево с предыдущим и применяет только различия.

### **2. Создание проекта**

Установите Node.js, затем создайте проект:

```bash
npm create vite@latest my-app -- --template react-ts
cd my-app
npm install
npm run dev
```

**Структура проекта:**

| Файл/папка | Назначение |
|------------|------------|
| `index.html` | Точка входа, корневой контейнер `<div id="root">` |
| `src/main.tsx` | Создание корня и рендеринг приложения |
| `src/App.tsx` | Корневой компонент |
| `src/index.css` | Глобальные стили |
| `vite.config.ts` | Конфигурация Vite |

### **3. Первый компонент**

```tsx
function App() {
  return <h1 className="title">Привет, мир!</h1>;
}

export default App;
```

**Отличия JSX от HTML:**

- `class` → `className`
- `for` → `htmlFor`
- Все теги должны закрываться: `<img src="..." />`
- В фигурных скобках `{}` можно вставлять выражения JavaScript

```tsx
const userName = "Иван";
function App() {
  return (
    <div>
      <h1>Привет, {userName}!</h1>
      <p>2 + 2 = {2 + 2}</p>
    </div>
  );
}
```

### **4. Рендеринг и виртуальный DOM**

```tsx
import { createRoot } from "react-dom/client";
import App from "./App";

const root = createRoot(document.getElementById("root")!);
root.render(<App />);
```

**Как работает обновление:**

1.  При изменении состояния React создаёт новое виртуальное дерево.
2.  Алгоритм сравнения (reconciliation) находит различия.
3.  React применяет минимальные изменения к реальному DOM.
