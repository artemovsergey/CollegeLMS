# Практическая работа 15. Создание компонентов

### **Тема занятия**

---

### **Цель работы**

Научиться создавать компоненты React, передавать props и отображать данные.

---

### **Задание**

Создайте приложение на Vite (react-ts) и реализуйте:

1.  Компонент `Greeting`, принимающий props `name` и `timeOfDay` («утро», «день», «вечер») и выводящий приветствие.
2.  Компонент `Card`, отображающий карточку пользователя: имя, возраст, город. Данные передавайте через props.
3.  Компонент `UserList`, который принимает массив пользователей и рендерит список карточек.
4.  Массив данных из 5 пользователей — в отдельном модуле `data.ts`.
5.  Заголовок страницы «Пользователи» и список карточек на главной странице.

---

### **Пример кода**

```tsx
// data.ts
export type User = { id: number; name: string; age: number; city: string };

export const users: User[] = [
  { id: 1, name: "Иван", age: 20, city: "Москва" },
  { id: 2, name: "Мария", age: 19, city: "Санкт-Петербург" },
  { id: 3, name: "Олег", age: 21, city: "Казань" },
];
```

```tsx
// UserCard.tsx
type UserCardProps = { user: User };

function UserCard({ user }: UserCardProps) {
  return (
    <div className="card">
      <h3>{user.name}</h3>
      <p>{user.age} лет, {user.city}</p>
    </div>
  );
}

export default UserCard;
```

---

### **Требования к отчёту**

- Приложение запускается через `npm run dev`.
- Список из 5 карточек корректно рендерится.
- Код опубликован в репозитории GitHub (ветка `practice-15`).
