### **Задание**

Создайте приложение «Менеджер задач» (ToDo):

1.  Форма добавления задачи: текстовое поле + кнопка «Добавить».
2.  Список задач с чекбоксом «выполнено» и кнопкой «Удалить».
3.  Счётчик выполненных задач.
4.  Фильтры: «Все», «Активные», «Выполненные».
5.  Сохранение задач в `localStorage` через кастомный хук `useLocalStorage`.
6.  При пустом списке — сообщение «Задач нет. Добавьте первую!».

### **Пример кода**

```tsx
function TaskItem({
  task,
  onToggle,
  onDelete,
}: {
  task: Task;
  onToggle: (id: number) => void;
  onDelete: (id: number) => void;
}) {
  return (
    <li>
      <input type="checkbox" checked={task.done} onChange={() => onToggle(task.id)} />
      <span className={task.done ? "done" : ""}>{task.title}</span>
      <button onClick={() => onDelete(task.id)}>Удалить</button>
    </li>
  );
}
```

Хук `useLocalStorage`:

```tsx
function useLocalStorage<T>(key: string, initial: T) {
  const [value, setValue] = useState<T>(() => {
    try {
      const saved = localStorage.getItem(key);
      return saved ? JSON.parse(saved) : initial;
    } catch {
      return initial;
    }
  });

  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value));
  }, [key, value]);

  return [value, setValue] as const;
}
```
