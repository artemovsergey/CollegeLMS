### **1. Подъём состояния**

Когда несколько компонентов работают с одними данными — состояние поднимается в общего родителя, а изменения передаются через колбэки.

```tsx
function App() {
  const [task, setTask] = useState("");

  return (
    <div>
      <TaskInput value={task} onChange={setTask} />
      <TaskPreview text={task} />
    </div>
  );
}

function TaskInput({ value, onChange }: { value: string; onChange: (v: string) => void }) {
  return <input value={value} onChange={e => onChange(e.target.value)} />;
}

function TaskPreview({ text }: { text: string }) {
  return <p>Превью: {text || "пусто"}</p>;
}
```

**Управляемый компонент** — значение input хранится в state и передаётся через `value` + `onChange`.

### **2. Контекст**

Контекст позволяет прокидывать данные глубоко по дереву без пропсов:

```tsx
const ThemeContext = createContext("light");

function App() {
  return (
    <ThemeContext.Provider value="dark">
      <Toolbar />
    </ThemeContext.Provider>
  );
}

function Toolbar() {
  const theme = useContext(ThemeContext);
  return <div className={`theme-${theme}`}>Панель</div>;
}
```

Контекст оправдан для данных, которые нужны многим компонентам: тема, язык, текущий пользователь. Для локального состояния лучше обычные props.

### **3. Рефы**

```tsx
function FocusInput() {
  const inputRef = useRef<HTMLInputElement>(null);

  useEffect(() => {
    inputRef.current?.focus();
  }, []);

  return <input ref={inputRef} />;
}
```

`useRef` также хранит мутабельное значение, не вызывая перерисовку.

### **4. Хранение данных**

- **localStorage** — для простого сохранения на устройстве.
- **Zustand** — лёгкое глобальное состояние.
- **Redux Toolkit** — предсказуемое состояние для больших приложений (slice, actions, thunk).
