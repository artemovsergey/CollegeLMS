### **Цель работы**

Закрепить условный рендеринг и работу со списками в React.

---

### **Задание**

Доработайте приложение из практической работы 15:

1.  Добавьте фильтр «Показать только совершеннолетних» (checkbox) — список пересчитывается через `.filter()`.
2.  Если после фильтрации список пуст — выводите сообщение «Нет пользователей, удовлетворяющих условию».
3.  Добавьте компонент `UserDetails`, который получает `user | null` и показывает детали: при `null` — «Пользователь не выбран», иначе — имя, возраст, город, статус («В сети»/«Не в сети» через тернарный оператор).
4.  Рядом с каждым пользователем — кнопка «Выбрать», по клику которой пользователь попадает в `UserDetails` (подъём состояния).

---

### **Пример кода**

```tsx
function UserList({ users }: { users: User[] }) {
  const [onlyAdults, setOnlyAdults] = useState(false);
  const [selected, setSelected] = useState<User | null>(null);

  const visible = onlyAdults ? users.filter(u => u.age >= 18) : users;

  return (
    <div>
      <label>
        <input
          type="checkbox"
          checked={onlyAdults}
          onChange={e => setOnlyAdults(e.target.checked)}
        />
        Только совершеннолетние
      </label>

      {visible.length === 0 ? (
        <p>Нет пользователей, удовлетворяющих условию</p>
      ) : (
        visible.map(u => (
          <div key={u.id} className="row">
            <span>{u.name}, {u.age}</span>
            <button onClick={() => setSelected(u)}>Выбрать</button>
          </div>
        ))
      )}

      <UserDetails user={selected} />
    </div>
  );
}
```
