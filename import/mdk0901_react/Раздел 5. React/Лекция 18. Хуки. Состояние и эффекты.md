### **1. Состояние компонента**

**Состояние (state)** — данные компонента, которые могут меняться. При изменении состояния React перерисовывает компонент.

```tsx
import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Счётчик: {count}</p>
      <button onClick={() => setCount(count + 1)}>+1</button>
    </div>
  );
}
```

**Функциональное обновление** — когда новое значение зависит от предыдущего:

```tsx
setCount(prev => prev + 1);
```

### **2. Эффекты**

`useEffect` выполняет побочные действия после рендера: подписки, запросы, таймеры.

```tsx
import { useEffect, useState } from "react";

function Clock() {
  const [time, setTime] = useState(new Date());

  useEffect(() => {
    const timer = setInterval(() => setTime(new Date()), 1000);
    return () => clearInterval(timer);
  }, []);

  return <p>{time.toLocaleTimeString()}</p>;
}
```

**Правила зависимостей:**

- `[]` — эффект выполняется один раз при монтировании.
- `[value]` — эффект перезапускается при изменении `value`.
- Без массива — после каждого рендера (используется редко).
- Функция очистки (в примере — `clearInterval`) выполняется при размонтировании.

Загрузка данных:

```tsx
useEffect(() => {
  fetch("/api/users")
    .then(res => res.json())
    .then(data => setUsers(data));
}, []);
```

### **3. Мемоизация**

```tsx
import { useMemo, useState } from "react";

function ExpensiveList({ numbers }: { numbers: number[] }) {
  const doubled = useMemo(
    () => numbers.map(n => n * 2),
    [numbers]
  );
  return <ul>{doubled.map(n => <li key={n}>{n}</li>)}</ul>;
}
```

`useMemo` кэширует результат вычислений, `useCallback` — функцию. Применяйте их осознанно: на маленьких объёмах данных они не нужны.
