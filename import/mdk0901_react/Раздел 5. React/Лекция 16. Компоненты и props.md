### **1. Компоненты и их виды**

**Компонент** — функция, которая принимает props и возвращает JSX.

```tsx
function Greeting() {
  return <h2>Добро пожаловать!</h2>;
}

export default Greeting;
```

Правила именования: имя компонента **обязательно с заглавной буквы** — иначе React примет его за HTML-тег.

### **2. Props**

**Props** — объект, который родитель передаёт ребёнку. Дочерний компонент не может изменить свои props (они read-only).

```tsx
type UserCardProps = {
  name: string;
  age?: number;
};

function UserCard({ name, age = 18 }: UserCardProps) {
  return (
    <div>
      <h3>{name}</h3>
      <p>Возраст: {age}</p>
    </div>
  );
}

// Использование
<UserCard name="Иван" age={20} />
```

- `age?: number` — необязательное свойство.
- `age = 18` — значение по умолчанию.
- В JSX пропсы-значения передаются в кавычках, пропсы-выражения — в фигурных скобках.

### **3. Дети компонентов**

Пропс `children` позволяет встраивать одни компоненты в другие:

```tsx
type CardProps = { title: string; children: React.ReactNode };

function Card({ title, children }: CardProps) {
  return (
    <div className="card">
      <h3>{title}</h3>
      <div>{children}</div>
    </div>
  );
}

<Card title="Заметка">
  <p>Произвольное содержимое</p>
</Card>
```

### **4. Практические примеры**

Композиция: список карточек из массива данных:

```tsx
const users = [
  { id: 1, name: "Иван", age: 20 },
  { id: 2, name: "Мария", age: 19 },
];

function UserList() {
  return (
    <div>
      {users.map(user => (
        <UserCard key={user.id} name={user.name} age={user.age} />
      ))}
    </div>
  );
}
```

Обратите внимание: при рендеринге списков каждому элементу задаётся уникальный `key`.
