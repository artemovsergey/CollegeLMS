### **1. Условный рендеринг**

В React нет специальных конструкций вроде `@if` — используется обычный JavaScript.

```tsx
function Greeting({ isLoggedIn }: { isLoggedIn: boolean }) {
  if (isLoggedIn) {
    return <h2>Добро пожаловать!</h2>;
  }
  return <h2>Пожалуйста, войдите</h2>;
}
```

Тернарный оператор внутри JSX:

```tsx
function Status({ online }: { online: boolean }) {
  return <p>{online ? "В сети" : "Не в сети"}</p>;
}
```

Логическое И — когда при `false` ничего не рендерим:

```tsx
function Notifications({ count }: { count: number }) {
  return (
    <div>
      {count > 0 && <span>Уведомлений: {count}</span>}
    </div>
  );
}
```

### **2. Рендеринг списков**

```tsx
const tasks = ["Купить продукты", "Сделать домашку", "Полить цветы"];

function TaskList() {
  return (
    <ul>
      {tasks.map((task, index) => (
        <li key={index}>{task}</li>
      ))}
    </ul>
  );
}
```

**Рекомендации по `key`:**

- Используйте стабильные идентификаторы (id из БД), а не индекс.
- Ключ нужен React, чтобы отслеживать элементы при обновлениях.

Фильтрация и пустой список:

```tsx
function CompletedTasks({ tasks }: { tasks: Task[] }) {
  const done = tasks.filter(t => t.completed);
  if (done.length === 0) {
    return <p>Задач пока нет</p>;
  }
  return (
    <ul>
      {done.map(t => <li key={t.id}>{t.title}</li>)}
    </ul>
  );
}
```

### **3. Рендеринг по ключам**

```tsx
const scores: Record<string, number> = {
  Иван: 5,
  Мария: 4,
  Олег: 3,
};

function ScoreTable() {
  return (
    <ul>
      {Object.entries(scores).map(([name, score]) => (
        <li key={name}>{name}: {score}</li>
      ))}
    </ul>
  );
}
```
