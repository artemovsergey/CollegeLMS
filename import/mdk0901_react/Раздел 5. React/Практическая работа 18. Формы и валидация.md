### **Цель работы**

Реализовать форму с валидацией и отправкой данных на сервер.

---

### **Задание**

Создайте форму регистрации (React Hook Form + Zod):

1.  Поля: имя (мин. 2 символа), email (формат email), пароль (мин. 6 символов), подтверждение пароля (совпадает с паролем).
2.  Ошибки под полями, красная рамка у некорректных полей.
3.  Кнопка «Зарегистрироваться» блокируется на время отправки (`disabled`).
4.  Отправка POST на `https://jsonplaceholder.typicode.com/users` (тестовый сервер).
5.  Успешный ответ — сообщение «Регистрация успешна», ошибка сервера — текст ошибки.

---

### **Пример кода**

```tsx
import { useForm } from "react-hook-form";
import { z } from "zod";
import { zodResolver } from "@hookform/resolvers/zod";

const schema = z
  .object({
    name: z.string().min(2, "Имя — минимум 2 символа"),
    email: z.string().email("Некорректный email"),
    password: z.string().min(6, "Минимум 6 символов"),
    confirm: z.string(),
  })
  .refine(data => data.password === data.confirm, {
    message: "Пароли не совпадают",
    path: ["confirm"],
  });

type FormValues = z.infer<typeof schema>;

function RegisterForm() {
  const {
    register,
    handleSubmit,
    formState: { errors, isSubmitting },
  } = useForm<FormValues>({ resolver: zodResolver(schema) });

  const onSubmit = async (data: FormValues) => {
    try {
      const res = await fetch("https://jsonplaceholder.typicode.com/users", {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify(data),
      });
      if (!res.ok) throw new Error(`HTTP ${res.status}`);
      alert("Регистрация успешна");
    } catch (err) {
      alert(err instanceof Error ? err.message : "Ошибка сервера");
    }
  };

  return (
    <form onSubmit={handleSubmit(onSubmit)} className="form">
      <label>Имя
        <input {...register("name")} className={errors.name ? "invalid" : ""} />
        {errors.name && <span className="error">{errors.name.message}</span>}
      </label>
      {/* email, password, confirm — аналогично */}
      <button type="submit" disabled={isSubmitting}>
        {isSubmitting ? "Отправка..." : "Зарегистрироваться"}
      </button>
    </form>
  );
}
```
