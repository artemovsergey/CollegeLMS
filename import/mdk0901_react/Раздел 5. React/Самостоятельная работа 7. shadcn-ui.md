# Самостоятельная работа 7. Сборка интерфейса на shadcn/ui

### **Тема занятия**

---

### **Цель работы**

Самостоятельно собрать интерфейс на основе готовой UI-библиотеки (shadcn/ui).

---

### **Задание**

Создайте страницу «Настройки профиля»:

1.  Карточка с аватаром (круглое изображение), именем и должностью.
2.  Форма: имя, email, город (Select), переключатель «Уведомления по email» (Switch), ползунок «Громкость уведомлений» (Slider).
3.  Кнопки «Сохранить» и «Отмена» (Button с вариантами `default` и `outline`).
4.  Показ сохранённого состояния через Toast/Sonner после нажатия «Сохранить».
5.  Адаптивность: на узких экранах (до 768px) карточка и форма складываются в колонку.

---

### **Начало работы**

```bash
npm create vite@latest profile-settings -- --template react-ts
cd profile-settings
npm install
npx shadcn@latest init
npx shadcn@latest add button input select switch slider sonner card avatar
```

Подключение Toaster в корневом компоненте:

```tsx
import { Toaster } from "@/components/ui/sonner";
import { toast } from "sonner";

<Toaster />
<Button onClick={() => toast.success("Профиль сохранён")}>Сохранить</Button>
```
