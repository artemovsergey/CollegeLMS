### **1. Сервисный слой**

В React нет встроенного DI-контейнера, как в Angular. Роль сервисов выполняют обычные модули и кастомные хуки:

```tsx
// services/userService.ts
export async function getUsers(): Promise<User[]> {
  const res = await fetch("/api/users");
  if (!res.ok) throw new Error("Не удалось получить пользователей");
  return res.json();
}
```

Использование через хук:

```tsx
function useUsers() {
  const [users, setUsers] = useState<User[]>([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    getUsers().then(setUsers).finally(() => setLoading(false));
  }, []);

  return { users, loading };
}
```

Для глобальных сервисов (авторизация, тема) применяется контекст:

```tsx
const AuthContext = createContext<AuthValue | null>(null);

export function useAuth() {
  const ctx = useContext(AuthContext);
  if (!ctx) throw new Error("useAuth вне AuthProvider");
  return ctx;
}
```

### **2. Кастомные хуки**

```tsx
function useLocalStorage<T>(key: string, initial: T) {
  const [value, setValue] = useState<T>(() => {
    const saved = localStorage.getItem(key);
    return saved ? JSON.parse(saved) : initial;
  });

  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value));
  }, [key, value]);

  return [value, setValue] as const;
}
```

Хук `useFetch` для типовых запросов:

```tsx
function useFetch<T>(url: string) {
  const [data, setData] = useState<T | null>(null);
  const [error, setError] = useState<string | null>(null);

  useEffect(() => {
    fetch(url)
      .then(res => {
        if (!res.ok) throw new Error(`HTTP ${res.status}`);
        return res.json();
      })
      .then(setData)
      .catch(e => setError(e.message));
  }, [url]);

  return { data, error };
}
```

### **3. UI-библиотеки**

| Библиотека | Особенности |
|------------|-------------|
| **shadcn/ui** | Компоненты-первоисточники в проекте, Tailwind, полная кастомизация |
| **MUI** | Готовая тема Material Design, богатый набор компонентов |
| **Ant Design** | Корпоративные приложения, таблицы, формы |

**shadcn/ui** — компоненты копируются в проект и настраиваются как обычный код, без лишней обёртки:

```bash
npx shadcn@latest add button
```

```tsx
import { Button } from "@/components/ui/button";

<Button variant="outline">Отмена</Button>
```
